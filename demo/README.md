# Kelvin Carlos

Site de produção do portfólio. Publicado na rota **`/`**.

## Como rodar localmente

```bash
cd demo
npm install
npm run dev
```

Abre em `http://localhost:5173`. A rota `/demo` redireciona para `/`.

## Onde editar conteúdo

- Contato, copy e localização: `src/data/site.ts`
- Trabalhos e imagens: `src/data/projects.ts`
- Serviços: `src/data/services.ts`
- Depoimentos: `src/data/testimonials.ts`
- Incluso: `src/data/included.ts`
- Menu: `src/data/navigation.ts`
- Fotos: `public/images/`

Instagram e e-mail estão como placeholder em `site.ts`.

## Stack

React, TypeScript, Vite, React Router, Tailwind CSS, shadcn/ui, Aceternity UI, Lucide.
