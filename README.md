# KCSA STUDIO

Portfólio do **KCSA STUDIO**. A demo para o cliente está na pasta `demo/` e é publicada na rota `/demo`.

## Local

```bash
cd demo
npm install
npm run dev
```

Abre em `http://localhost:5173/demo`.

## Vercel

```bash
npx vercel --prod
```

O site fica em `https://seu-projeto.vercel.app/demo`.
